## Описание программы

**Random Password Generator** - это GUI-приложение для генерации надёжных случайных паролей. Приложение позволяет настраивать длину пароля (от 4 до 32 символов), выбирать типы символов (буквы, цифры, спецсимволы), генерировать пароль, копировать его в буфер обмена, а также сохранять историю всех сгенерированных паролей с датой и параметрами.

### Возможности:
- ✅ Регулировка длины пароля с помощью ползунка (4–32 символа)
- ✅ Выбор наборов символов: буквы (A-Z, a-z), цифры (0-9), специальные символы (!@#$...)
- ✅ Генерация случайного пароля по заданным параметрам
- ✅ Копирование сгенерированного пароля в буфер обмена
- ✅ Таблица истории с временной меткой, паролем, длиной и использованными наборами символов
- ✅ Автоматическое сохранение истории в JSON-файл и загрузка при запуске
- ✅ Очистка всей истории паролей (с подтверждением)
- ✅ Валидация: проверка выбора хотя бы одного типа символов

## Инструкция по запуску

### Требования:
- Python 3.6 или выше
- Установленная библиотека Tkinter (обычно идёт в комплекте с Python)

### Запуск:
1. Откройте терминал или командную строку
2. Перейдите в директорию проекта:
   ```bash
   cd password_generator
Запустите приложение:

bash
python password_generator.py
Примеры использования
Генерация пароля:
Настройте параметры:

Длина пароля: передвиньте ползунок на значение (например, 16)

Типы символов: отметьте нужные чекбоксы (например, "Буквы" и "Цифры")

Нажмите кнопку "Сгенерировать"

В поле "Пароль" появится случайный пароль, например aG7kL2pQ9rT5vN8m

Нажмите "Копировать" – пароль будет скопирован в буфер обмена

Работа с историей:
Каждый сгенерированный пароль автоматически добавляется в таблицу истории с указанием:

Даты и времени генерации

Самого пароля

Длины пароля

Использованных наборов символов (буквы, цифры, спецсимволы)

Нажмите "Очистить историю" – удалит все записи из истории (появится запрос подтверждения)

Тестовые данные (примеры для проверки):
Попробуйте выполнить следующие действия:

Действие	Ожидаемый результат
Установить длину 8, отметить только «Буквы», нажать «Сгенерировать»	Пароль из 8 букв (пример: aBcDeFgH)
Установить длину 12, отметить «Буквы» и «Цифры», сгенерировать	Пароль содержит буквы и цифры (пример: a1B2c3D4e5F6)
Отметить все три чекбокса (буквы+цифры+символы), длина 16	Пароль содержит буквы, цифры и спецсимволы (пример: A!b2@C#d4$E%f6^)
Снять все чекбоксы, нажать «Сгенерировать»	Появится предупреждение: "Выберите хотя бы один тип символов"
Сгенерировать 3 разных пароля	В таблице истории появятся 3 записи с временными метками
Нажать «Копировать» после генерации	Пароль можно вставить (Ctrl+V) в любом другом месте
Закрыть программу и открыть снова	История загрузится из файла history.json, записи сохранятся
Валидация данных
Приложение проверяет:

Если ни один тип символов не выбран – выдаётся предупреждение и пароль не генерируется

Длина пароля ограничена ползунком (минимум 4, максимум 32 символа)

При копировании пустого поля (если пароль ещё не сгенерирован) – выводится предупреждение

При очистке истории требуется подтверждение пользователя
