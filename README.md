## Описание программы

Weather Diary - это GUI-приложение для ведения дневника наблюдений за погодой. Приложение позволяет добавлять записи о погоде (дата, температура, описание, наличие осадков), фильтровать записи по дате и температуре, сохранять и загружать данные в формате JSON.

### Возможности:
- ✅ Добавление записей с указанием даты, температуры, описания погоды и осадков (да/нет)
- ✅ Фильтрация записей по точной дате
- ✅ Фильтрация по температуре (выше или ниже заданного значения)
- ✅ Сохранение данных в JSON-файл
- ✅ Загрузка данных из JSON-файла
- ✅ Показ всех записей (сброс фильтров)
- ✅ Валидация вводимых данных (формат даты, числовое значение температуры, непустое описание, осадки только "да"/"нет")

## Инструкция по запуску

### Требования:
- Python 3.6 или выше
- Установленная библиотека Tkinter (обычно идёт в комплекте с Python)

### Запуск:
1. Откройте терминал или командную строку
2. Перейдите в директорию проекта:
   ```bash
   cd weather_diary

Примеры использования
Добавление записи:
Заполните все поля формы:

Дата (ДД.ММ.ГГГГ): "22.04.2026"

Температура (°C): "15"

Описание: "Солнечно, небольшой ветер"

Осадки (да/нет): "нет"

Нажмите кнопку "Добавить запись"

Запись появится в списке справа

Фильтрация:
По температуре выше: Введите число (например, "10") в поле "Фильтр по температуре" и нажмите "ВЫШЕ" – покажутся записи с температурой >= 10°C

По температуре ниже: Нажмите "НИЖЕ" – записи с температурой <= заданного числа 

По дате: Введите дату (например, "22.04.2026") в поле "Фильтр по дате" и нажмите "Фильтр по дате" – останутся записи только за этот день

Для сброса фильтров и показа всех записей нажмите "ПОКАЗАТЬ ВСЕ"

Сохранение и загрузка:
Нажмите "Сохранить в JSON" – данные сохранятся в файл weather_diary.json

Нажмите "Загрузить из JSON" – данные загрузятся из файла weather_diary.json

Тестовые данные (примеры для проверки):
Попробуйте добавить следующие записи для тестирования:

Дата	Температура	Описание	Осадки
22.04.2026	15	Солнечно, ясно	нет
23.04.2026	8	Пасмурно, моросит дождь	да
24.04.2026	20	Жарко, безоблачно	нет
25.04.2026	5	Холодно, сильный ветер	нет
26.04.2026	2	Снег с дождём	да
После добавления попробуйте:

Отфильтровать записи с температурой выше 10°C – должны остаться 22.04 и 24.04

Отфильтровать записи с температурой ниже 0°C – не найдено (корректное сообщение)

Отфильтровать по дате 23.04.2026 – должна показаться только запись за 23 апреля

Сохранить данные в JSON, закрыть приложение, затем загрузить обратно

Валидация данных
Приложение проверяет:

Все поля должны быть заполнены

Дата должна соответствовать формату ДД.ММ.ГГГГ (например, 22.04.2026)

Температура должна быть целым числом

Описание не может быть пустым

Поле осадков должно содержать только "да" или "нет" (без учёта регистра)

При фильтрации по температуре требуется ввести число
